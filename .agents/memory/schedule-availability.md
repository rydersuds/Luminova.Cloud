---
name: Schedule availability
description: The chosen behavior when a project is marked as having no available schedule.
---

Marking a project schedule as unavailable hides the project-level board but preserves all saved task records. Clearing the setting restores the board.

**Why:** The user explicitly chose a reversible hide behavior rather than deleting tasks or leaving the board read-only.

**How to apply:** Treat schedule availability as a visibility setting. Never clear or delete task data when it is toggled off, and make sure restoring availability exposes the saved tasks again.
