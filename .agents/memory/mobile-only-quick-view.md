name: Mobile-only Quick View
description: Product scope for the Quick View overview and its navigation.
---

Quick View should be only on mobile, using the app's phone layout breakpoint (under 768px).

**Why:** The user explicitly requested “Quick view should be only on mobile.” Desktop users should use Command Center instead of a second overview.

**How to apply:** Keep Quick View out of desktop navigation and redirect desktop access to its route to Command Center. Preserve it in phone navigation.
