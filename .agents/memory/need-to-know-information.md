---
name: Need-to-know information
description: User-directed information hierarchy across the construction workspace.
---

Across the entire app, keep information on a need-to-know basis: prioritize actionable facts, remove redundant introductions, and make secondary explanations expandable.

**Why:** The user explicitly chose the entire app, rather than just Command Center and Financials, for redundancy cleanup.

**How to apply:** Preserve primary actions, entity identities, financial amounts, important statuses, errors, approval/budget warnings, and access-control meaning. This is a presentation rule, not authorization to delete data or weaken permissions.

Command Center financial cards are an explicit exception to expandable secondary explanations: omit their Details controls and descriptions without substituting tooltips or always-visible explanations. Do not apply this exception to Details controls elsewhere.

**Why:** The user requested simpler Command Center financial cards while keeping disclosures on other pages unchanged.

**How to apply:** Keep this exception scoped to the Command Center financial summary, preserving labels, figures, icons, loading/error states, and responsive layout.
