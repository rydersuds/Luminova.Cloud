---
name: Entry agreement replacement
description: Durable behavior for directly uploaded project entry agreements.
---

Directly uploading an entry agreement replaces the project's current designation, but does not delete the previous contract document. The new file is stored privately and explicitly classified as a contract with the entry-agreement flag.

**Why:** Users need a clear current agreement without losing historical project documents or the existing private-file access model.

**How to apply:** Any future agreement upload, import reconciliation, or document-management change should preserve one current designation per project and retain prior agreements as ordinary contract records.
