---
name: Filter presentation
description: Product requirement for compact browsing controls.
---

Keep filtering options behind a Filters button rather than displaying all filter controls permanently. Search remains directly available.

**Why:** The user explicitly asked for a button that opens the filters menu to reduce visible controls.

**How to apply:** Preserve this pattern when adding or changing directory/list filters. Active filtering should remain apparent after the menu closes, and reopening should retain selections.
